# 中税云检智能体配置系统 · 报价方案 App

内部用的第 1 步报价计算器。浏览器直接打开，不联网，不注册，不收款。

这一步只算价。不做知识库、角色智能体配置台、老板助理开通，也不做运营系统。

## 怎么打开

1. 进入文件夹 `zsyj-quote-app`。
2. 双击 `index.html`，或把文件拖进 Chrome、Edge、Firefox。
3. 要交给客户时，点「打印 / 导出一页报价」。纸张选 A4，关掉浏览器的页眉页脚，可以另存为 PDF。

不装任何东西也能用。如果要用本地地址打开，在本目录执行：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 锁定常数

页面上这三项不能改，只作标价和对外展示：

| 名称 | 金额 |
| --- | --- |
| 财税顾问（ADVISOR） | 24000 元/年 |
| 代账，一般纳税人一户（BOOKKEEP） | 6000 元/年 |
| 对外价值锚点 | 30000 元 |

价值锚点永远是 24000 + 6000。某一项没计入套餐时，锚点照样展示，不等于全年满配交付。

点某一档，整张表回到该档默认，手改的数字会被盖掉。当前档再点一次，同样重置。

| 档位 | 签约费用 | 端口 | mini | 手机 | 笔记本 | Studio | 显示器 | 计入顾问 | 计入代账 | 首年陪跑 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 低端 2.5 万 | 25000 | 2 | 3300 | 4500 | 空 | 空 | 空 | 否 | 是 | 8000 |
| 高端 5 万 | 50000 | 3 | 5600 | 4500 | 9250 | 空 | 空 | 是 | 是 | 8000 |
| VIP 10 万起 | 100000 | 4 | 3799 | 空 | 空 | 空 | 空 | 是 | 是 | 15000 |

端口含义：

- 低端 2 口：Mac mini M4 16G+256G + iPhone 15 Pro 256G。不含笔记本，不含 Studio。
- 高端 3 口：低端那套把 mini 提到 24G，再加 MacBook Pro 14 M4 16G+512G。
- VIP 4 口：高端套装改为全新官配，再加 Mac Studio 64G+ 全新。官网价要手填，页面不编。

VIP 的 mini 默认 3799，只是 16G+256G 的官全新参考，不是 24G 的官网价。Studio 的中古 Mid 34800 只写在参考区，不会自动填进价格格。

低端、高端按 99 新计价。VIP 按全新官配计价。

## 公式

空着按 0。格式不对的格子会标红，公式里也先按 0，避免整页算出空白。

- 硬件 = mini + 手机 + 笔记本 + Studio + 显示器
- 财税包 = （计入顾问 ? 24000 : 0） + （计入代账 ? 6000 : 0） + 检测
- 剩余 = 签约费用 − 硬件 − 财税包
- 硬件占比 = 签约费用 > 0 ? 硬件 / 签约费用 × 100 : 0
- 上限 = VIP 为 60，其他档为 35
- 超限 = 签约费用 > 0 且占比 > 上限
- 次年陪跑 = 首年陪跑标价 × 0.5
- 过紧 = 剩余 < 5000
- 四件套 = mini、手机、笔记本、Studio 都大于 0（显示器不算）

五折只乘「首年陪跑标价」这一行，不乘签约费用，也不乘含硬件的合计。

开关：

- 打开 = 计入套餐成本，从签约费用里扣，并按全年交付。
- 关闭 = 只展示锚点，不扣费用，不按全年交付。

低端默认只计入代账。高端和 VIP 默认顾问、代账都计入。

陪跑标价从剩余里列支，不含硬件，不含财税包。软件席位没有写进签约费用。

## 四行报价

报价单始终在右侧，打印时只留下这一页：

1. 硬件一次性：只列大于 0 的设备。
2. 软件席位：固定写「未列入实时签约价」。不编软件价格，也不把 0 元写成软件售价。
3. 陪跑：首年标价，旁边是次年本行五折。
4. 财税包：按开关拆开顾问和代账。检测没填就写「尚无定价，不编数字」。

客户支付的是签约费用。四行不是在签约费用外面再加一遍。

## 页面上的提示

这些提示给销售看，不印在给客户的报价单上：

- 低端四件套：低端不要加回笔记本和 Studio。四件套加上财税包会亏。
- 剩余不到 5,000：剩余不到 5,000，陪跑和软件空间过紧。
- 高端并且顾问仍计入：把签约费用改为 65,000 后再看剩余，或关闭「计入财税顾问」，改成有限场次，合同写明场次。
- VIP 没填 Studio：先填官网标价，再核对 60% 硬件上限。
- 硬件占比超过本档上限：单独用红字标出。

## 不包含

- 软件席位没有实时签约价。
- 税收风险检测不预填价格，也不能在页面里编一个数出来。
- 不认定发票税目，不认定硬件算销售还是租赁，这两项交给财税顾问复核。
- 报价不扩展到公司运营系统，也不设计新的运营后台。运营如果要做，只用现有 Grok Bot。
- 不做第 2 步：知识库产品、角色智能体配置、老板助理开通、运营系统。
- 不注册、不支付、不收集证件。客户名称可留空，只出现在本机的报价单上。

## 对外验收只说到这些

- 知识库入库并可检索。
- 标准角色智能体上线：低端 3 个，高端 5 个，VIP 按合同定制。
- 老板私人助理为独立账号，可日常使用。
- 陪跑：每周复盘，每月验收。
- 代账：计入时为本档一户。
- 顾问全年计入还是限次，以合同书面为准。

16G 用于云端智能体。本地大模型对应高端 mini 的 24G，或 VIP 的 Studio 64G 及以上。

政策咨询免费但有上限，只讲路径，不对个案税额下结论。

次年只把首年陪跑标价打五折，硬件不重复计，代账和顾问续费另列。
