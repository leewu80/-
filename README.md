# 果择 · 二手 Apple 笔记本多端比价

给客户演示用的单页工具：按机型、芯片、内存、存储、显卡、成新度、价格和渠道筛选，把同一配置在五个渠道里并排看，再用成新度和金额打出一个综合分，标出当前结果里的前 1～3 条和理由。

界面是中文。内置卖家、价格、备注是虚构样本。当面拿到的真实报价可以用「录入报价」写进这台浏览器，和样本走同一套筛选、对比和打分。纳入最多 3 条后，可以打开「客户方案」打印。

## 启动

需要 Node.js 20 或以上。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:5173](http://localhost:5173)。

其他命令：

```bash
npm test        # 打分和清单解析
npm run build   # 类型检查并打包到 dist
npm run preview # 预览打包结果
```

## 五个渠道

| 标识 | 渠道 |
| --- | --- |
| `jd` | 京东二手（拍拍） |
| `web` | 全网二手（转转、爱回收等归在这里） |
| `live` | 科技数码苹果电脑主播挂价 |
| `xianyu` | 闲鱼同款 |
| `hqb` | 华强北市场报价（赛格、明通等档口当面价） |

对比区始终按这五列排。某一列是空的，表示当前筛选下这一家没有同配置。华强北是档口当面报价，和平台挂牌、主播价、闲鱼个人价分开比。

## 打分

逻辑在 `src/scoring/score.ts`，不依赖界面。

- 成新分是固定档：官翻 100、99 新 96、95 新 90、9 成新 78、8 成新 62、7 成新 48。
- 金额分只和**同配置**比。同配置指系列、机型、年份、芯片、内存、存储、显卡都相同。等于这组均价记 50 分；比均价便宜或贵大约 25%，分别到 100 或 0。只有一条时没有比较基准，金额分记 50。
- 综合分 = 成新分 × 成新占比 + 金额分 × 金额占比。默认各 50%。页面上可以改权重，也可以切「更看金额」「更看成新」。
- 分组和均价都按**当前筛选结果**算。筛掉某个渠道后，剩下的机器会重新比较。

这样不会出现「只要绝对价格低，旧款 8GB 就总排第一」。

## 主要路径

```text
src/data/listings.ts     演示样本（58 条，五个渠道都有）
src/data/quotes.ts       本场报价、与样本合并、方案最多 3 条
src/data/source.ts       读清单的入口，也是以后接接口的位置
src/data/channels.ts     五个渠道的名称和说明
src/scoring/score.ts     成新分、金额分、综合分、推荐理由
src/filters.ts           筛选
src/App.tsx              页面组装
src/components/          筛选、权重、推荐、并排对比、明细、录入、方案
```

明细里能看到机型、芯片、内存、存储、显卡、成新度、价格、渠道、卖家/主播、链接和备注。演示数据没有 `linkUrl`，界面只显示「链接占位」，不会生成可点击的死链。接口如果带回 `http(s)` 地址，明细里才会出现「打开来源」。

## 接真实数据

1. 让接口 `GET {VITE_LISTING_API}/listings` 返回 `Listing` 数组，字段见 `src/types.ts`。
2. 复制 `.env.example` 为 `.env.local`，写上：

   ```bash
   VITE_LISTING_API=https://your-api.example/api
   ```

3. `src/data/source.ts` 的 `loadListings` 会改走这个地址，并用 `parseListings` 校验。校验失败时页面会提示，并退回内置样本。
4. 渠道 `channel` 用 `jd` / `web` / `live` / `xianyu` / `hqb`。新的平台先归到这五类，避免对比区被拆散。
5. 有真实链接时再填 `linkUrl`。不要填无法打开的地址。
6. 打分继续放在 `src/scoring/score.ts`。接口只负责挂牌，不负责名次，这样权重调整不必改后端。

## 本场报价和客户方案

右上角「录入报价」按渠道、机型、芯片、内存、存储、显卡、成新度、价格写入一条挂牌。它存在浏览器本地，刷新还在，并立刻进入当前这套打分。链接留空时仍然只显示占位。

「客户方案」最多放 3 条。可以从推荐卡或明细纳入，也可以一键填入当前前三名，再打印给客户。方案和报价都只在这台浏览器里，清站点数据会一起清掉。
